# DBX 차세대 API 확장 프로젝트 (Next-Gen API Expansion)

DBX의 핵심인 **5계층 하이브리드 스토리지(5-Tier Hybrid Storage)**와 **분산 그리드(Distributed Grid)** 제어 기능을 .NET, Python, Node.js 사용자들에게 공식적으로 노출하기 위한 전방위 API 확장 계획입니다.

## User Review Required

> [!IMPORTANT]
> **성능 최적화 및 비동기 모델 설계 결정**
> 1. **비동기 API 표준화**: 각 언어(.NET Task, Python await, JS Promise)와 고성능 Rust Future를 어떻게 효율적으로 연결할지에 대한 모델을 정의해야 합니다. 현재는 블로킹 모델 위주입니다.
> 2. **메트릭 데이터 구조**: 실시간 모니터링 데이터를 단순 JSON으로 넘길지, 고성능 처리를 위해 바이너리 구조체로 넘길지 결정이 필요합니다. (초기에는 직관적인 JSON 권장)

## Proposed Changes

### [Component] DBX FFI (`core/dbx-ffi`) - 게이트웨이 확장
모든 언어 바인딩의 기초가 되는 C-Compatible 인터페이스를 대폭 확장합니다.

#### [MODIFY] [lib.rs](file:///d:/ByteLogicCore/DBX/core/dbx-ffi/src/lib.rs)
- **DbConfig 구조체 및 생성자**: `ParallelismConfig`, `DurabilityLevel`, `StorageStrategy` 등을 포함한 전용 설정 객체 추가.
- **분산 그리드 API**: `dbx_grid_join`, `dbx_grid_status`, `dbx_grid_execute` 등 그리드 제어 함수군 추가.
- **메트릭 추출 API**: `dbx_get_metrics_json`을 통해 엔진 내부 상태(Hit Rate, Tier Usage) 추출 기능 추가.
- **비동기 쿼리 핸들러**: (Phase 2 계획) 쿼리 종료 시 콜백을 호출하는 비동기 브릿지 인프라 구축.

#### [MODIFY] [package.json](file:///d:/ByteLogicCore/DBX/packages/nodejs/package.json)
