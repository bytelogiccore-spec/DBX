# 🚧 예정 통지: 분산 엔진 성능 비교 및 벤치마크 아키텍처 (Performance Tests)

해당 문서는 DBX 쿼리 코어 엔진이 목표하는 확장성과 속도를 객관화하고, 싱글 노드 SQLite 엔진 대비 우위점을 실증하기 위한 벤치마크 스위트(Benchmark Suite) 고도화 예정 명세서입니다.

## [Added] 분산 쿼리 대규모 벤치마크 파이프라인
- `/benchmark` 워크플로우를 자동화하여, 1GB ~ 1TB 스케일의 대규모 합성 더미 데이터(`TPC-H` 등)를 기준으로 벤치마크 런타임 지표를 측정하는 모듈이 추가됩니다.
- 단일 스레드(ex: rusqlite) 환경 처리 시간과 DBX 멀티 워커 클러스터에서의 분산 조인/집계 실행 시의 Throughput(처리량) 비교 도구를 오픈합니다.

## [Performance] Shuffle 및 Salting 실효성 프로파일링
- Phase 4에서 구축된 **ShuffleSalting(ReplicateProbe, RandomDistributed)** 기능의 파급력을 프로파일링합니다.
- 데이터 극단치(Skew, 데이터 쏠림 현상) 환경을 인위 조작하여 스캔 시나리오를 구동한 뒤, Salting 옵션을 켰을 때와 껐을 때 워커 별로 균등한 작업 할당이 이루어지고 I/O 병목이 얼마나 개선되는지 통계 리포트를 작성할 수 있게 됩니다.

## [Changed] 성능 회귀(Regression) 방어 파이프라인
- 향후 기능 병합(Merge) 시마다 쿼리 엔진의 처리 속도가 이전 버전보다 저하(Regression) 되지 않았음을 판정하기 위해, `cargo bench` 아키텍처를 GitHub Actions(또는 내부 CI 스크립트)와 통합합니다.
- 초당 레코드 스캔 량, QUIC 송수신 단위 지연(인터리빙 지연), 그리고 최대 IOPS 등 세부 세션에 대한 정량적 Audit(감사)을 시행합니다.
